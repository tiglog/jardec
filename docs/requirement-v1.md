需求说明
=========


## 背景

使用 jadx 反编译 jar 包时，发现有些文件无法完整反编译，导致无法查看源代码，影响
开发效率。经测试，那些无法反编译的文件使用 Procyon 可以正常反编译。虽然没有全面测试，
但是两者结合使用，基本可以解决大部分 jar 包的反编译问题。

## 目标

创建一个 cli 工具，专门用于反编译 jar 包，结合使用 jadx 和 Procyon 两个工具，尽可能
完整地反编译 jar 包中的所有文件。

步骤：

step1: 使用 jadx 反编译 jar 包，获取反编译结果。
step2: 对于反编译失败的文件，使用 Procyon 进行反编译，获取反编译结果。
step3: 将两者的反编译结果进行合并，生成最终的反编译结果。
step4: 像 Procyon 一样，生成一个反编译报告，能够清晰地展示哪些文件未反编译成功。
